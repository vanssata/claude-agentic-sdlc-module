Demo · one task, start to finish

You type one line. The plugin routes the work.

A payment change goes through /ai-task in Claude Code. Cheap readers fan out on FAST, the risk tier picks the pipeline, STRONG plans and reviews, the guards keep every edit inside its step, and the change stops at your approval. Time is compressed about 6×.

01 / 08You type one line
    FAST
    haiku · low

    Three discovery readers in parallel, the red-test classifier, the release report. Reading is cheap, so it is done cheaply.

    BALANCED
    sonnet

    Compressed the findings into one task context and did the mechanical step that copies an existing pattern.

    STRONG
    opus · high

    Risk tier, plan, adversarial review, security review. One agent at a time, only where being wrong is expensive.

    EXPERT
    opus · xhigh

    Not launched. It is the last resort for T5 and for what STRONG cannot settle, and it asks before it starts.

    Every stage in the run is a file under .ai/reports/<task-id>/. No agent commits, pushes or merges. The pipeline ends with you.
