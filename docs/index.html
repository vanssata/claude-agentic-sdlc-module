01 / THE SYSTEM

Context. Constraints. Continuity.

Built for existing codebases, where legacy behaviour and unwritten rules matter as much as the next feature.

01⌘

Know the repository

Keep architecture, legacy behaviour and project policies in one .ai/ tree that both runtimes understand.

02↗

Match effort to risk

Keep a label change lightweight. Give payments, migrations and shared business logic the planning and review they need.

03⊞

Make scope explicit

Registered steps name the files they may touch. Hooks check edits and protect selected sensitive paths and operations.

04⇄

Carry decisions forward

Shared state, questions and handoffs help a task survive a new session or move between Claude Code and Codex.

02 / THE WORKFLOW

A clear path from request to review.

The risk tier sets the gates. The default solo profile keeps routine changes direct and adds structure as the stakes rise.

  1. 01

    Understand

    Context, impact and existing behaviour.

  2. 02

    Classify

    Workflow, risk tier and required gates.

  3. 03

    Plan

    Bounded steps and the required approvals.

  4. 04

    Implement

    Scoped changes and verification.

  5. 05

    Review

    Evidence, independent review and human handoff.

Conceptual flow. Exact stages and reviews follow the project's risk policy.

T0T1T2T3T4T5

From documentation to production migrations. Risk follows the behaviour affected, not the number of lines changed.

03 / QUICK START

Start with one
well-defined change.

Inspect the installation, initialise your repository, then describe one task. The same commands work in both runtimes.

Read the installation guide ↗
TERMINAL / INSTALL PREVIEW
git clone https://github.com/vanssata/claude-agentic-sdlc-module.git
cd claude-agentic-sdlc-module
./install.sh --dry-run
AFTER INSTALLING / IN YOUR PROJECT
# In Claude Code or Codex
/ai-init
/ai-task <describe one change>
/ai-status

Review the dry run, then run ./install.sh and restart your runtime. In Codex, review and trust the hooks through /hooks.
